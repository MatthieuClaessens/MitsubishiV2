## 📖 Overview
**Mitsubishi Lancer Evolution X - V2** is the complete modern evolution of the original concept. Built from the ground up to replace the legacy static version, this release focuses on robust component architecture, advanced performance optimization, and a radically aggressive UI/UX design.

> **💡 Note:** This is an independent personal project created for design and development practice, and is **not an official website** of Mitsubishi Motors.

🔗 **Live Preview:** [Explore the V2 App](https://mitsubishi-v2.vercel.app/)  
🔙 **Curious about the origins?** Check out the [Mitsubishi V1 (HTML/JS/Vite)](https://github.com/MatthieuClaessens/mitsubishi-site) repository.

---

## 🛠️ Tech Stack & Architecture

| Component | Technology | Role |
| :--- | :--- | :--- |
| **UI Library** | **React** | Component-driven user interface development. |
| **Framework** | **Next.js (App Router)** | Server-side rendering, routing, and modern React paradigms. |
| **Language** | **TypeScript** | Strict typing, robust data models, and maintainable codebase. |
| **Styling** | **Tailwind CSS v4** | Utility-first styling with modern CSS features and fluid layouts. |

---

## ⚡ Key Features
* **Modern App Architecture:** Organized using the Next.js App Router pattern for optimal loading speeds and SEO.
* **Component-Driven Design:** Decoupled sections (Hero, Intro, Legacy, Specs) built for scalability and reuse.
* **Advanced Motion & Layout:** Refined grid systems and micro-interactions delivering a high-end automotive feel.

## 🌐 Quick Start / Usage

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/MatthieuClaessens/mitsubishi-v2.git

# Navigate to the project directory
cd mitsubishi-v2

# Install dependencies
npm install

# Start the local development server
npm run dev
